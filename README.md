# Habit Tracker 🧠📆

A simple C++ console app that helps you build habits and track your progress daily.  
You can log daily reflections, track check-in streaks, and manage multiple habits — all from the terminal.

---

## 💡 Features

- Add new habits with a set duration
- Check-in daily with reflections
- View logs for each habit
- Track check-in streaks
- Save and load habit data automatically

---

## 🛠️ How It Works

- When you launch the app, it loads your saved habits from `habits.txt`
- You can add new habits, log daily updates, or check your progress
- Exiting the app saves all your habits and logs
